# Apps Script バックエンド（PIN方式）

`Code.gs` は Google Apps Script にコピー&ペーストして使う。管理者
(marusinsystem.home@gmail.com) のGoogleアカウントで、Driveと同じアカウントに
作成すること。

## デプロイ手順

1. https://script.google.com/ を開く（marusinsystem.home@gmail.com でログイン）
2. 「新しいプロジェクト」
3. プロジェクト名を適当に変更（例: 「長町倫理活動計画バックエンド」）
4. エディタに最初から入っている `myFunction` などのコードを全部消し、
   このフォルダの `Code.gs` の中身を丸ごと貼り付ける
5. 左メニューの歯車アイコン「プロジェクトの設定」→ 一番下「スクリプト プロパティ」
   → 「スクリプト プロパティを追加」
   - プロパティ: `APP_PIN`
   - 値: 使いたいPIN（例: `1234` など好きな数字・文字列）
   - 「保存」
6. 右上「デプロイ」→「新しいデプロイ」
   - 種類の選択（歯車アイコン）→「ウェブアプリ」
   - 説明: 何でもよい
   - 次のユーザーとして実行: **自分（Me）**
   - アクセスできるユーザー: **全員**
   - 「デプロイ」
7. 初回は権限確認画面が出る（自分のアカウントなので許可するだけ）
8. 発行された「ウェブアプリ」のURL（`https://script.google.com/macros/s/.../exec`
   の形）をコピーして、Claudeに伝える

## PINを変更したくなったら

手順5の「スクリプト プロパティ」の `APP_PIN` の値を書き換えて保存するだけ。
再デプロイもコードの変更も不要（全員に即座に反映される）。

## 動作確認

デプロイ後、以下のようなcurlコマンドでも直接テストできる（`<PIN>`と`<URL>`は
実際の値に置き換える）:

```bash
curl -X POST "<URL>" -H "Content-Type: text/plain" \
  -d '{"action":"load","pin":"<PIN>"}'
```

`{"ok":true,"exists":false}` のような応答が返れば正常（まだ保存データがない状態）。
